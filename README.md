# Maternity Leave Regulations in Europe

**Authors**: Sarah Puthiaparampil, Lara , Yankui

## General Instructions 

This is the repository for our "Maternity Leave Regulations" project.
This is a file to ensure the performance of our programs. 
Please read and follow these instructions before you start. 

We are using the R 4.5.2 version. There could be some issues with some packages if you are using a different version.

For a detailed list of loaded packages, please refer to "env_setup.R" under the
root directory of our project.

## Usage 

If you directly want to look at our final presentation. Open the project.qmd file and render it.

Otherwise, please source the "env_setup.R" file. This will install all the
necessary packages and load necessary data sets.

Then, for single programs, simply source the corresponding R file under the
"Code" directory. For generating the final presentation, open the "project.qmd" file
under the root directory and render it.
